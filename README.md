trae手机版  

📱 TRAE 手机版（TRAE SOLO）
 
字节官方移动端，2026年5月上线，iOS/安卓免费，和电脑/网页三端实时同步 。
 
 
 
 
✅ 一、怎么下载
 
- iOS：App Store 搜 TRAE - SOLO 智能助手（iOS 16.6+） 
​
- 安卓：应用宝/华为/小米商店搜 TRAE，包名  com.bytedance.trae.overseas  
​
- 网页端：solo.trae.cn（不用装） 
​
- 桌面端：trae.cn 下载（Windows/Mac） 
 
 
 
✅ 二、最核心：手机遥控电脑（必用）
 
1. 电脑端打开 TRAE → 设置 → SOLO 移动端 → 开启 Phone Pairing 
​
2. 手机登录同账号 → 头像 → 设备管理 → 添加设备 → 选在线电脑 → 配对成功 
 
- 一部手机可控制多台电脑；任务在电脑跑，手机看进度、收结果 
 
 
 
✅ 三、手机端能干什么（MTC+Code 双模式）
 
📝 MTC模式（办公）
 
- 语音/文字生成：周报、报告、PPT大纲、方案、邮件、会议纪要 
​
- 数据处理：Excel分析、做图表、写结论 
​
- 拍照理解：拍白板/截图 → 自动整理成文档 
​
- 网页/论文：丢链接 → 摘要/翻译/要点 
​
- 飞书协同：自动发周报、整理纪要、传文件
​
- 定时任务：“明早9点发飞书周报”
 
💻 Code模式（开发）
 
- 远程写代码：手机发指令，电脑自动写/改/调试/修Bug 
​
- 项目管理：连GitHub、读代码库、查问题、写API文档 
​
- 实时看日志：手机看运行日志、代码diff、结果 
 
🎤 手机独有优势
 
- 语音优先：通勤直接说话发任务，不用打字 
​
- 三端同步：手机/电脑/网页实时同步，任务不中断 
​
- 云端执行：没电脑也能跑任务，结果推送到手机
 
 
 
✅ 四、典型场景
 
- 通勤：语音“生成上周工作总结PPT”，电脑自动做，下班看结果 
​
- 出差：手机远程改线上Bug、查日志、发版通知 
​
- 开会：手机记要点→自动纪要→发飞书群 
​
- 学习：拍论文→中文笔记→思维导图 
 
 
 
一句话：手机当电脑的AI遥控器，办公+写代码都能远程搞定，全中文、免费、不用邀请码 。
